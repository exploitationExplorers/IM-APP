# IM H5 回归用例

改完相关代码后跑对应节；新功能在文末按模板追加。

## 冒烟（每次验证至少跑）

1. 下载页点「开启聊天快捷版」→ 登录页
2. `15013938612` / `asd.12345` 登录成功 → 会话列表
3. 点开任意已有会话（优先有历史消息的）
4. PC：右侧出现聊天区；移动端：进入 `room` 全屏聊天

## C1 — 打开会话贴底（PC 重点）

相关：`pages/chat/room.vue` 滚动 / `scrollToBottom`

1. PC 视口登录后，从会话列表点开一个消息较多的会话
2. **期望**：进入后最新消息在视口底部（不必再往下拖）
3. 再切另一个会话，同样贴底
4. 移动端 Web：进入会话后同样贴底

断言提示：`Runtime.evaluate` 可查 `.msg-list .uni-scroll-view` 的 `scrollTop + clientHeight` 是否接近 `scrollHeight`（误差 < 80px）

## C2 — 输入框粘贴 / 换行后滚到最后一排（PC）

相关：composer textarea `scrollComposerCaretIntoView`

1. 打开会话，聚焦输入框
2. 粘贴一段超过 6 行的文字（或连续 Enter 换行直到出现滚动条）
3. **期望**：无需滚轮，光标所在最后一排在输入框可视区内
4. 关闭「回车发送」时按 Enter 换行，同样应跟到底

## C3 — 回车发送 + Shift+Enter 换行（PC）

相关：`chatSettings`、`room.vue` `onComposerKeydown`、聊天设置页

1. 进入「我的 → 聊天设置」（或设置里「回车键送出消息」）
2. 打开「回车键送出消息」
3. 回聊天：输入 `hello` → Enter → **应发出**，输入框清空
4. 输入 `a` → Shift+Enter → `b` → **应换行且不发送**
5. 刷新或等 30s 后再进设置页 → 开关仍为开（防「过一会自己关掉」）

## C4 — 移动端 Web 发图（非华为 App）

相关：`pickLocalImages`、`sendImageMessage`（H5 选图）

1. 移动端视口进会话 → 加号 → 相册/图片
2. 若浏览器文件选择器无法被 MCP 接管：**标 blocked**，写明需人工点选一张图；能注入则发一张小图
3. **期望**：出现图片气泡或明确失败 toast（不要静默无反应）

> 华为 App 发图不在此用例；人工真机验。

## C5 — 桌面布局切换

1. PC 视口：存在桌面侧栏 / 会话列 / 房间列
2. 切到 390 宽：三栏消失，出现底部 Tab
3. 切回 1280：三栏恢复

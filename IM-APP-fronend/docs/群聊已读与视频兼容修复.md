# 群聊已读、清理记录与 App 视频兼容修复

## 修复范围

- App 群聊发送成功回调兼容 `Seq` 字段，并在原生库落盘后异步回填消息序号。群已读仍只按会话轮询聚合游标，不按群成员逐个查询。
- H5 清除聊天记录改用 Web SDK 支持的 `deleteConversationAndDeleteAllMsg`；App 保持原生 `clearConversationAndDeleteAllMsg`。
- App 视频封面兼容原生 `getVideoCover` 返回的 `{ path }`，封面提取后上传并写入消息 `snapshotUrl`。
- 视频展示和转发兼容 App 原生桥的 `VideoElem`、`VideoUrl`、`SnapshotUrl` 等 PascalCase 字段。
- 视频转发前统一生成 OpenIM 标准 `VideoElem`，补齐类型、UUID、尺寸等字段，避免服务端字段校验失败。
- 视频消息长按菜单增加“保存视频”：App 下载远程视频后写入系统相册，H5 触发浏览器下载。

## 发布与验证

这些变更均在前端 TypeScript/Vue 层，可通过 WGT 发布，不要求替换原生视频插件。

1. App 发送视频，发送中可显示本地画面，成功后消息包含 `snapshotUrl` 并显示封面。
2. 另一账号打开群聊后，发送者 App 的单勾变双勾；无需重新进入房间。
3. App 长按视频，分别验证“转发”和“保存视频”。首次保存时允许系统相册权限。
4. H5 群详情点击“清除聊天记录”，不再出现 `reading 'apply'`，消息列表清空。
5. H5/App 分别查看同一条 App 视频，封面和播放地址保持一致。

Linux 侧群容量、测试用户和群已读回归命令见 `IM-APP-server/scripts/testdata/README.md`。

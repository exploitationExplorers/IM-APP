## 本项目内置埋点

H5 开发模式或配置 `VITE_PERF_REPORT_URL` 时自动启用，见 `src/utils/perf.ts`：

| 指标名 | 触发点 |
|--------|--------|
| `LCP` / `FCP` / `CLS` | PerformanceObserver |
| `app:cold-start` | `App.vue` onLaunch → `userStore.bootstrap()` 完成 |
| `chat:load-conversations` | `chatStore.loadConversations()` |
| `chat:load-messages` | `chatStore.loadMessages()` |
| `chat:load-messages:sdk` | OpenIM `getAdvancedHistoryMessageList` |
| `chat:load-more-messages` | `chatStore.loadMoreMessages()` |
| `chat:room-enter-conversation` | `room.vue` → `enterConversation()` |
| `chat:room-group-meta` | `room.vue` → `refreshGroupMeta()` |
| `chat:room-first-messages` | `room.vue` 首次渲染消息 |

可选上报：在 `.env` 设置 `VITE_PERF_REPORT_URL=https://your-collector/perf`

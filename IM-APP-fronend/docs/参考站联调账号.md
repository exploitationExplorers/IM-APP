## 访问方式

1. 用 Chrome / Edge 打开上述地址
2. 先按 `F12` 打开开发者工具
3. 切换到**手机模式**（Toggle device toolbar，建议 375 宽度）
4. 再进行浏览或登录，避免桌面布局干扰对照

## 注册页对照要点（移动端）

- 左上角返回箭头，非底部圆形返回键
- 仅「区号 + 手机号」「验证码」两行，无密码框
- 底部通栏白色「注册」按钮
- 协议文案为白色，链接「用户协议」「隐私权政策」白色下划线

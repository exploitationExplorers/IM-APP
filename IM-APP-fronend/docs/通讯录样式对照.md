# 通讯录页面样式对照（参考站抓取）

> 参考地址：https://qwa.11skrmx6.net/contact  
> 抓取条件：Chrome DevTools 移动端模拟，视口 **375 × 812**，DPR 2，iPhone UA  
> 抓取时间：2026-08-12  
> 用途：对齐 `pages/contacts/index.vue` 视觉，换算按 uni-app **750 设计宽**（1px ≈ 2rpx）

## 12. 加号菜单与跳转页（2026-08-12 续抓）

### 加号下拉

| 属性 | 值 |
|---|---|
| 宽 | min 144px（288rpx） |
| 圆角 | 8px |
| 内边距 | 8px |
| 阴影 | `0 10px 15px -3px rgba(0,0,0,.1)` |
| 项高 | 36px，字号 14px，图标 20px，gap 8px |

三项：

1. 添加朋友 → `/pages/contacts/add-friend`（参考 `/contact/request`）
2. 添加群聊 → `/pages/contacts/scan`（参考 `/contact/request/scan`，扫码页）
3. 创建群聊 → `/pages/group/create`（参考 `/contact/groups/create`）

### 添加朋友

- 自定义顶栏：返回 + 标题「添加朋友」+ 扫码入口
- 搜索框占位：**搜索聊天号**（业务红线禁止按手机号搜人，故不照搬参考站「电话号码」文案）
- 底部固定主按钮「搜索」：高 48px，`#0a2fc2`，圆角 4px

### 添加群聊 / 扫二维码

- 全屏深蓝渐变背景
- 中央白色描边扫码框 + 提示「将二维码放入框内，即可自动扫描」
- 底部：我的二维码 / 从相册选取

### 创建群聊（两步）

1. **选择联络人**：搜索、排序、圆形勾选；顶栏「确认」未选灰底 `#e1e3ea`，已选变主色并显示 `确认(N)`；已选项以 chip 展示  
2. **创建群聊**：群头像占位、群名输入（最多 50 字，默认同成员昵称拼接）、群成员预览、底部「创建」

## 本轮已改的代码

1. 个人中心七行菜单改为直接引用子控件。原来的按钮 tag=1/2/3 与子控件 tag 冲突，布局时把通知设置、聊天设置、隐私的按钮本身缩成小控件，产生截图中的空白。
2. 编辑/二维码图标按 Android 内边距缩放；个人中心使用浅色状态栏。在自绘个人中心、会话列表、通讯录和聊天页面关闭 iOS 26+ 自动滚动边缘效果。头图本身无状态栏图案；顶部残影是否消失仍待运行截图确认。
3. 时间与发送状态移至气泡下方，成功/已读以勾号显示，失败和待核对保留状态。图片/视频不再带蓝色“已提交”底条。
4. 图片解析 camelCase/PascalCase 元数据，按 Android 规则计算横图、竖图及缺少尺寸时的布局；视频按 280×360rpx 上限等比显示，封面实际比例优先。

6. 置顶提示改为左侧色条、范围标题、单行预览、关闭入口；点击发送限制文案不会再误打开置顶。隐藏提示只作用于本次页面生命周期。
7. 引用消息把回复正文与引用预览分开，避免重复显示引用内容；自己的头像优先使用当前个人资料。
8. 通用业务列表按 contentView 宽度布局，避开群号复制等右侧 accessoryView。

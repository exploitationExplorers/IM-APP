# YanChat 对照与五项修复

本轮针对用户的 6 张截图：会话未读角标变成长条、向上浏览历史需反复滑动并点击加载、群历史边界弹窗、好友数量为 0、群邀请验证开关不可见。Android 版本为 `0.3.7-history` / versionCode `11`，沿用 staging 包名及签名，覆盖安装，不卸载或清数据。

## YanChat 实际证据与本项目调整

目标为用户提供的 `YanChat-3.2.0.apk`，SHA-256：`8144707b09d5e5260c65624b5efa0e0992e39a047cbaecf841a1f8d8a22f2f3d`。本轮使用 REA 6.4.0 / JADX 0.7.1 静态分析；未安装、运行竞品或访问其服务器。具体 Evidence ID 和文件哈希见 `.workflow/scratch/20261115-history-ui-fix/rea-evidence-index.json`。

| 问题 | YanChat 证据 | 本项目修复 |
| --- | --- | --- |
| 未读角标 | 会话适配器将数量限制为 99+；免打扰使用小点。官方 aapt2 解码布局另证实数字角标 16 × 16 dp、红色圆形、10 sp、单行居中，免打扰点 6 × 6 dp。 | Android 会话使用固定 16 dp 红圆和居中数字，99+ 缩小字体，免打扰使用 6 dp 点；补聊天 Tab 总未读。原实现依赖文字和内边距撑尺寸，导致竖长形。 |
| 连续上滑历史 | `BaseChatViewModel.checkAndPerformPreload` 在首个可见位置 ≤ 5 且未加载、未到末页时预读；仓库使用 SDK 消息游标、请求数量及 isEnd。 | 在接近更早消息时自动预读；同一次滑动只要分页有推进就可继续，加载中及同游标不重复请求，初始静止不连扫数据库。移除“点击加载更早消息”文字，等待时用小转圈。保留 Compose 消息 ID 稳定键。 |
| 群历史边界提示 | 已检查的历史路径未恢复竞品群权限和边界刷新策略，不能据此宣称没有这种规则。 | 已有经过验证的本地边界继续过滤历史，后台刷新失败记入调试资讯，不打断浏览；没有可用边界时仍禁止展示未经校验的群历史，并给简短失败提示。保留刷新与限频，不删除权限控制。 |
| 好友数量为 0 | `ContactsViewModel.buildContactItems` 使用同一份 friends 列表的 size 构造联系人标题及好友行。 | 本服务端仅首页统计总数，后续页 total 为 0；客户端原来逐页覆盖总数。现保留首页总数，且不低于累计去重好友数，重新搜索或刷新时重新计算。 |
| 群邀请验证开关 | `SettingMyPrivacyFragment.initUI` 绑定好友验证、群邀请验证两个独立 Material Switch。 | Android 隐私页改用独立固定占位的官方 Switch，关闭轨道清晰可见，标题可换行；读取两项真实值后才允许修改，保存时携带另一项真实值，失败保持原值。截图中的设备缺失此前未能复现，不冒称已经确认具体渲染根因。 |

另修正一个结束状态缺口：远程历史查询的 isEnd 不能在本地分页仍有剩余记录时让界面提前停止。本地读取与 SDK 补洞的结束状态现在合并判断，网络等待不会阻止继续读本地下一页。

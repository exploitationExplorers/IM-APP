# 原生 UI 复用与首轮验收

> 当前开发状态（0.3.0）：见 [功能与 UI 对齐记录](原生功能与UI对齐-20261113/功能与UI对齐记录.md)。下文的 0.1/0.2 阶段功能边界、测试数字和安装包哈希为历史记录；不能用于判断当前是否全量完成。新版增加业务/媒体页面和安全登录恢复，仍需真实账号与 Mac/iPhone 验收。


用户要求：原生重构用于改善性能与稳定性，界面保持现有 uni-app 版本。项目品牌仍为“易可聊”，不采用新视觉稿，不复制竞品品牌或图标。

## 复用方式

复用旧页面的布局、样式数值、原图片、文案与交互。Android 使用 Compose、iOS 使用 UIKit 重建原生视图。旧 Vue 模板和 CSS 作为实现基准，不能直接在原生控件中运行；聊天列表、消息气泡和输入区不通过 WebView 套旧页面。法律原文可以本地只读 WebView 展示。

同一仓库增加 `IM-APP-android/` 与 `IM-APP-ios/`，在 `codex/native-bootstrap` 分支开发。目录承载两套平台工程，分支隔离变更，这两者同时使用。保留旧 uni-app 以便版本维护和逐页对照；当前不替换旧客户端、不部署服务端。

## 样式约定

`rpx = 当前窗口逻辑宽度 / 750`，映射到 dp / point；`auth-modern.scss` 的固定 `px` 保持逻辑尺寸，不与 rpx 混算。系统状态栏、安全区域、键盘与手势区域由原生 Insets 处理。大字体、横屏、平板及无障碍仍需单独验收。

登录保留蓝渐变 `326deg` 与原色标；普通屏 Logo 为 56、标题为 26、输入高 52、按钮高 50。高度不超过 650 的小屏按旧媒体查询使用 44 的 Logo 和较小顶部间距。普通页面保留旧版密码登录结构，已默认连接用户授权的现有 HTTPS 业务后端，无需进入菜单。地址覆盖和离线样例仍收在 Logo 长按菜单中。

列表标题、搜索框、行高、头像、底栏及文本气泡按旧组件换算；底栏文案不能擅自改成“个人中心”，发送文案不能改成其他按钮文字。系统字体的字形和字重可能有平台差异，最终以同设备截图与实际触控检查验收，不能仅凭源码宣布像素一致。

## 资源与防漂移

`contracts/ui-parity/v1/asset-source-manifest.json` 记录 30 项资源的源文件、SHA-256、转换方式和双端目标。旧 PNG、法律 HTML 原样复制；底栏等图标使用旧版实际引用的 SVG 转为透明 PNG。Logo 从 2134 × 2134 下采样到 168 × 168，按 56 逻辑像素显示，减少解码内存。

```powershell
node scripts/native/sync_ui_assets.mjs
python -X utf8 scripts/native/verify_ui_parity.py
```

新下载、浏览器工作目录、Gradle、模拟器、临时文件和本地截图都使用 D 盘 `.native-cache/`。原 uni-app 与后端不由这些脚本修改。

## 验收方法与实际限制

旧 H5 登录页已在本机渲染为视觉基准：逻辑宽 360、高 616、DPR 2，并注入 24 的状态栏占位。临时 Vite 配置禁用代理与业务路径，浏览器阻断外部请求；未登录生产。基准来自真实旧页面，不是重新画的示意图。Android 使用 360 × 640 的模拟器窗口，比较时排除系统导航区域。

本地证据在 `.native-cache/verification/`：`uniapp-login-baseline.png`、`android-parity-login-final.png` 及 `android-ui-parity-validation.json`。基准截图支持首轮布局核对，不等同旧 App 全部页面、全部机型截图或性能验收。

本次登录修复后 Android 26 项单元测试、Debug 编译通过，5 项本机 TLS transport 场景通过；新版默认地址与离线入口有独立模拟器记录，真实账号主页仅源码 / 合成流程验证，尚无真实账号运行截图。iOS 的 8 项工程、资源、fixture 和发布阻断静态检查通过；27 项 XCTest 已写，当前无 Mac，Swift / Xcode 编译及 iOS UI 运行均未执行。Lint 的覆盖限制和警告详见工程构建记录，不应简化为完整发布门禁通过。

正式 UI 验收每页至少覆盖：正常 / 加载 / 空 / 错误状态、长昵称、长文本、键盘弹出和收起、返回、权限拒绝、浅色及项目规定主题、多尺寸、字体缩放。业务验收另验证真实消息与同步；本地样例持续显示“不联网、不送达”，不绘制虚假的已读、送达或同步完成状态。

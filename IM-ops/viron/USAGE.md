# IM 运维平台 — 使用指南

> 团队共享部署、账号体系与线上安全说明见：[团队共享部署与安全说明.md](./团队共享部署与安全说明.md)。

## 1. 环境要求

- **Node.js** ≥ 22.19.0
- **npm** ≥ 10
- Windows / macOS / Linux 均可

## 2. 首次启动

```bash
cd d:\接单\IM\IM-ops\viron

# 安装依赖（已 clone 的仓库首次需要执行）
npm ci

# 复制环境变量
cp .env.example .env

# 启动开发服务器
npm run dev
```

启动后访问 **http://127.0.0.1:8080**

## 3. 登录

| 字段 | 默认值 |
|------|--------|
| 用户名 | `admin` |
| 密码 | `Change-me-before-start-1` |

> 首次登录后建议在 `.env` 中修改 `ADMIN_PASSWORD`，然后重启服务。

## 4. 功能总览

| 功能模块 | 入口（侧栏） | 说明 |
|----------|-------------|------|
| 环境总览 | 首页 | 已连接数据库/服务器概览 |
| 数据库工作台 | `数据库` | 查询、表设计、数据编辑（支持 MySQL + PostgreSQL） |
| Redis 工作台 | `Redis` | Redis 键值浏览与操作 |
| SSH 终端 | `SSH` | Web 终端远程管理服务器 |
| 连接管理 | `连接池` | 管理所有数据库/SSH/Redis 连接 |
| 审计日志 | `审计` | 所有操作记录 |

## 5. 添加 PostgreSQL 连接（IM 业务数据库）

1. 侧栏点击 **连接池**
2. 点击 **新建连接**
3. 填写 IM 项目数据库信息：
   - **引擎**：`PostgreSQL`
   - **主机**：`8.210.72.157`
   - **端口**：`5433`
   - **用户名**：`im`
   - **密码**：`im123456`
   - **默认数据库**：`im_app`
4. 可选择 **连接方式**：
   - TCP 直连（服务器 PostgreSQL 已开放端口时）
   - SSH 隧道（需先在 SSH 连接中配置跳板机）
5. 点击 **测试连接** → 成功后 **保存**

> **注意**：运维平台自身的 `.env` 文件配置的是平台内部的元数据库（默认 SQLite），不需要改成 IM 的数据库。IM 业务数据库是通过上面的「连接池」功能添加和管理的。

## 6. 数据库工作台使用

### 6.1 浏览表结构

1. 侧栏切换到 **数据库**
2. 左上角选择已添加的 PostgreSQL 连接
3. 左侧树选择 Schema（如 `public`）
4. 展开 `表` 分类，双击表名即可查看表数据

### 6.2 SQL 查询

1. 点击工具栏 **新建查询**（或快捷键）
2. 编辑器中书写 SQL（支持 PostgreSQL 语法补全：`RETURNING`、`ILIKE`、`JSONB` 函数等）
3. `Ctrl+Enter` 执行当前语句
4. 结果在下方网格展示

### 6.3 表设计器

1. 在对象树右键表名 → **设计表**（或双击）
2. 修改字段、索引、外键、检查约束
3. 底部 **SQL 预览** 实时显示将执行的 `ALTER TABLE` 语句
4. 点击 **保存** 执行变更

### 6.4 数据编辑

1. 双击表名打开数据网格
2. 直接在单元格编辑数据
3. 点击 **+** 新增行，选中行点击 **删除**
4. 修改完成点击 **提交**（批量事务提交）

### 6.5 导入导出

- 在自动化工作台中可配置：
  - **导出**：CSV 或 SQL 格式
  - **导入**：CSV 文件导入到指定表

## 7. SSH 终端

1. 先在 **连接池** 中添加 SSH 连接（主机、端口、用户名、密钥或密码）
2. 侧栏切换到 **SSH**
3. 选择连接 → 打开终端
4. 可用于管理 Docker 容器、查看日志、操作 OpenIM 等

## 8. Redis 工作台

1. 在 **连接池** 中添加 Redis 连接
2. 侧栏切换到 **Redis**
3. 支持键值浏览、搜索、TTL 管理、批量操作

## 9. 常见问题

### 启动失败：端口被占用

修改 `.env` 中的 `PORT=8080` 为其他端口。

### 连接 PostgreSQL 报错

- 检查 PostgreSQL 是否允许远程连接（`pg_hba.conf`）
- 检查防火墙是否开放端口
- 确认用户名/密码正确

### 结构同步不支持 PostgreSQL

当前版本数据库结构同步仅支持 MySQL 连接间操作，PostgreSQL 连接暂不支持此功能。

## 10. 配置参考（.env）

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `PORT` | 监听端口 | `8080` |
| `HOST` | 监听地址 | `127.0.0.1` |
| `ADMIN_USERNAME` | 管理员用户名 | `admin` |
| `ADMIN_PASSWORD` | 管理员密码 | `Change-me-before-start-1` |
| `SESSION_TTL_HOURS` | 会话有效期（小时） | `1080`（45天） |
| `CONNECTION_IDLE_MINUTES` | 空闲连接释放时间 | `30` |
| `AUDIT_RETENTION_DAYS` | 审计日志保留天数 | `30` |

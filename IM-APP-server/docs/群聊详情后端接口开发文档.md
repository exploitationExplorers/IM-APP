# 群聊详情后端接口开发文档

> 版本：2026-08-13
> 适用项目：IM-APP-server（Go/Gin + PostgreSQL + MinIO + OpenIM）

## 1. 功能边界

本次开发覆盖：

- 群详情权限信息。
- 编辑群名称、群头像、群公告。
- 所有有效群成员查看群二维码字符串。
- 扫码解析、公开群直接加入、审核群提交申请。
- 修改“我在本群的昵称”。
- 举报群聊。
- 修复审核群可绕过申请直接加入的问题。
- 修复文件完成、查询及头像引用的跨用户越权问题。

以下能力由前端直接调用 OpenIM SDK，不新增 Go 消息接口：图片与视频、搜索聊天记录、清空聊天记录、消息免打扰、置顶聊天。

群全员禁言等管理操作由业务接口写入后同步 OpenIM。OpenIM 会下发系统通知；前端按参考站展示为居中提示（如 `张三: [全体禁言]`），不作为普通消息响铃。`group.updated` 只同步群资料，全员禁言走独立的 `group.mute`，避免一次开关叠出多条通知。

所有 `:id` 均为纯数字群号，例如 `100001`；数据库内部仍使用 UUID。

## 2. 群详情

```http
GET /api/v1/groups/{id}
Authorization: Bearer <accessToken>
```

仅有效群成员可访问。除原有字段外增加：

```json
{
  "id": "100001",
  "name": "项目群",
  "avatar": "https://files.example/group.jpg",
  "ownerId": "user-uuid",
  "memberCount": 5,
  "announcement": "今晚开会",
  "allowMemberAddFriend": true,
  "myRole": "owner|admin|member",
  "myNickname": "群内昵称",
  "joinMode": "open|approval",
  "allMuted": false,
  "permissions": {
    "canEditProfile": true,
    "canEditAnnouncement": true,
    "canViewQRCode": true,
    "canManageMembers": true,
    "canEditMyNickname": true,
    "canReport": true
  }
}
```

权限字段用于前端显示控制；所有写接口仍在服务端重新鉴权。

## 3. 编辑群名称、头像和公告

复用群设置接口，所有字段均为可选的部分更新：

```http
PUT /api/v1/groups/{id}/settings
Content-Type: application/json
Authorization: Bearer <accessToken>
```

```json
{
  "name": "新群名称",
  "avatarFileId": "ready-file-uuid",
  "announcement": "新公告",
  "allowMemberAddFriend": false,
  "joinMode": "approval",
  "allMuted": false
}
```

规则：

- 仅群主、管理员可修改。
- 群名称去首尾空格后为 1～100 个 Unicode 字符。
- 公告最多 2000 个 Unicode 字符，空字符串表示清空。
- 头像必须是操作者本人上传、状态为 `ready`、用途为 `avatar`、类型为 `image/*` 且不超过 10 MiB 的文件。
- 不接受客户端直接传头像 URL。
- 数据库更新与 OpenIM Outbox 入队处于同一事务。
- 成功返回更新后的群详情。

头像上传顺序：

```text
POST /files/uploads
PUT uploadUrl
POST /files/uploads/{fileId}/complete
PUT /groups/{id}/settings
```

## 4. 群二维码

### 4.1 获取二维码字符串

```http
GET /api/v1/groups/{id}/qrcode
```

所有有效群成员都可获取；非成员不可获取。后端返回字符串，前端使用项目已有 `qrcode` 包生成图片：

```json
{
  "groupId": "100001",
  "payload": "{\"type\":\"group\",\"token\":\"random-token\"}",
  "expiresAt": "2027-08-13T12:00:00Z"
}
```

二维码不写入可信群资料，只携带不可猜的 token；群资料及权限始终以后端解析结果为准。

### 4.2 扫码解析

```http
POST /api/v1/groups/qrcode/resolve
```

```json
{ "payload": "{\"type\":\"group\",\"token\":\"random-token\"}" }
```

响应：

```json
{
  "group": {},
  "joined": false,
  "joinMode": "open",
  "nextAction": "enter|join|apply"
}
```

解析接口只读，不允许“打开扫码结果页即自动入群”。

### 4.3 确认扫码加入

```http
POST /api/v1/groups/qrcode/join
```

```json
{
  "payload": "{\"type\":\"group\",\"token\":\"random-token\"}",
  "remark": "申请说明"
}
```

响应动作：

- `enter`：已经是成员，前端直接进入群聊。
- `joined`：`joinMode=open`，后端已加入群并写入 OpenIM Outbox。
- `pending_approval`：`joinMode=approval`，后端已创建或复用待审核申请。

`POST /groups/{id}/join` 同样严格遵守 `joinMode`，审核群返回 409，不能绕过申请。

## 5. 我的群昵称

```http
PUT /api/v1/groups/{id}/me/nickname
```

```json
{ "nickname": "群内显示名称" }
```

- 仅当前有效群成员可修改自己。
- 最多 32 个 Unicode 字符；空字符串恢复全局昵称。
- 成员列表返回 `nickname`（全局）、`groupNickname` 和 `displayName`。
- 修改通过 Outbox 同步到 OpenIM 群成员资料。

## 6. 举报群聊

```http
POST /api/v1/groups/{id}/reports
```

```json
{
  "reason": "spam|fraud|pornography|violence|harassment|other",
  "description": "补充说明"
}
```

- 仅有效群成员可举报。
- 描述最多 1000 个 Unicode 字符。
- 同一用户对同一群的待处理举报保持幂等。
- 返回 `{ id, status: "pending", createdAt }`。

## 7. 状态码

| HTTP | 含义 |
|---|---|
| 400 | 字段格式、长度、文件类型或状态不合法 |
| 401 | 未登录或 token 失效 |
| 403 | 非群成员、无管理权限或引用他人文件 |
| 404 | 群、二维码或文件不存在/已失效 |
| 409 | 审核群必须申请、已存在冲突状态 |
| 500 | 数据库或 Outbox 异常 |

## 8. 验收重点

- 普通成员能获取群二维码字符串，但不能编辑群资料。
- 已入群扫码返回 `enter`；公开群返回 `joined`；审核群返回 `pending_approval`。
- 审核群不能直接调用 `/join` 绕过申请。
- 他人的 fileId、pending 文件和非图片文件都不能设置为群头像。
- 群名称、头像、公告和群昵称最终与 OpenIM 一致。
- 群详情权限字段与写接口真实权限一致。
- 举报重复提交不会产生多条待处理记录。
